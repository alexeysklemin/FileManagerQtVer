# FileManagerQtVer

Файловый менеджер должен полностью копировать работу с файлами ОС Linux и ОС Windows.
Также должен иметь возможность скачивать файлы по ссылкам, с ftp:\ серверов и архивировать, разархивировать файлы. Кроме того шифровать архивы, файлы и папки(можно упростить сделав зашифрованную папку чере архив).
Опционально добавление расширений.
Интерфейс должен быть реализован в псевдо-графической среде. Опционально графическое решение.
